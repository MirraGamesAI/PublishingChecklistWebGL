### What's new

1. New rewarded ad check: the reward is still given when the player leaves the ad open for a long time and closes it later
2. New localization check: the language is saved only when the player changes it in the game, and until then it comes from the platform at every launch
3. Yandex: timer interstitials are allowed in real-time games with levels longer than 5 minutes or no levels, after a 2-second countdown with the game paused
4. Yandex: turn-based games can show an interstitial right after a player's move, with no countdown
5. Yandex ad placement rules join the sources

### Important

1. The new checks take the next free numbers, B27 to B29 and H12, and no existing number or wording changed
2. Release notes now live in one file per version under `Documentation/Changelogs`, and `CHANGELOG.md` is their index
